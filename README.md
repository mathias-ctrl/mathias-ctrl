### Plataforma SaaS Multi-tenant para Gestão de Pedidos e Impressão Distribuída

Sistema para gestão de pedidos e impressão térmica em restaurantes, lanchonetes e operações de delivery.

**Principais características técnicas:**

- arquitetura SaaS multi-tenant;
- API REST com autenticação JWT e controle de acesso por perfil;
- painel administrativo e interface pública de pedidos;
- gerenciamento de produtos, adicionais, pedidos e setores de impressão;
- armazenamento de imagens compatível com o protocolo S3;
- integração entre servidor central e agentes locais de impressão;
- processamento em tempo real por WebSockets;
- infraestrutura containerizada.

**Stack:** Python, FastAPI, PostgreSQL, React, TypeScript, Redis, WebSockets, S3 e Docker.
